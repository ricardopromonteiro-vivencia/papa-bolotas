# Progressive Web App (PWA) Setup

This document describes the PWA configuration for the Papa Bolotas webapp.

## Overview

The Papa Bolotas webapp is configured as a Progressive Web App (PWA) with offline-first capabilities, enabling it to work without an internet connection and be installed on devices like a native application.

## Configuration

### Service Worker

The service worker is automatically generated by `vite-plugin-pwa` during the build process. It provides:

- **Automatic updates**: New versions are installed automatically when available
- **Offline functionality**: Core application functionality works without internet
- **Smart caching**: Different caching strategies for different resource types

### Caching Strategies

1. **NetworkFirst** (Supabase API):
   - Attempts network request first
   - Falls back to cache if network fails
   - Timeout: 10 seconds
   - Cache duration: 24 hours
   - Perfect for data that needs to be fresh but should fallback offline

2. **CacheFirst** (Images & Fonts):
   - Checks cache first, only hits network if not cached
   - Cache duration: 30 days (images), 1 year (fonts)
   - Ideal for static assets that rarely change

3. **StaleWhileRevalidate** (CSS & JS):
   - Serves from cache immediately
   - Updates cache in background
   - Cache duration: 7 days
   - Best balance for application code

### Manifest Configuration

The web app manifest (`manifest.json`) is generated inline in `vite.config.ts` with:

- **Name**: Papa Bolotas POS
- **Short Name**: Papa Bolotas
- **Theme Color**: #2563eb (blue)
- **Display Mode**: standalone (fullscreen app experience)
- **Orientation**: any (supports portrait and landscape)
- **Language**: pt-PT (Portuguese)
- **Categories**: business, productivity, finance

### Icons

All required PWA icons are generated from the base `icon.svg` file:

- `icon-192x192.png` - Standard small icon
- `icon-512x512.png` - Standard large icon
- `icon-192x192-maskable.png` - Maskable small icon with safe zone
- `icon-512x512-maskable.png` - Maskable large icon with safe zone
- `apple-touch-icon.png` - iOS home screen icon (180x180)
- `favicon-32x32.png` - Browser favicon
- `favicon-16x16.png` - Browser favicon (small)

### Maskable Icons

Maskable icons include 20% padding to ensure the logo is visible within the safe zone on all devices. Different Android manufacturers apply different shapes (circle, rounded square, squircle) to home screen icons.

## Generating Icons

To regenerate icons from the SVG source:

```bash
npm run generate-icons
```

This script uses Sharp to convert the SVG into all required PNG formats.

## Offline Functionality

### What Works Offline

- ✅ View and process orders
- ✅ Manage menu items
- ✅ Adjust stock levels
- ✅ View order history
- ✅ Generate receipts
- ✅ View sales reports

### What Requires Online

- ⚠️ Initial authentication (after app installation)
- ⚠️ Data synchronization with other devices
- ⚠️ Real-time updates from other terminals

### Sync Behavior

When the application goes offline:

1. All changes are stored locally in IndexedDB
2. A sync queue tracks pending changes
3. Connection status is displayed to the user

When the connection is restored:

1. The sync engine processes the queue automatically
2. Conflicts are resolved using last-write-wins strategy
3. User is notified when sync completes

## Troubleshooting

### Service Worker Not Updating

If changes aren't appearing after deployment:

1. Open DevTools → Application → Service Workers
2. Check "Update on reload"
3. Click "Unregister" to force fresh install
4. Reload the page

### Cache Issues

To clear all caches:

```javascript
// Run in browser console
caches.keys().then(names => {
  names.forEach(name => caches.delete(name));
});
```

### Manifest Not Loading

Verify in DevTools → Application → Manifest that all fields are present and icons load correctly.
